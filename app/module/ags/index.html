AGS

Agency Grounding System

Grounds the agent in one coherent stance — binds the World boundary, the Self Model, and Policy into a single structure: who the agent is, where it stands, and what it may commit to; checks over-allocation, constraint violation, and value drift.

not yet built The AGS system is in the model — see the Element Set — but has no implementation yet. Its policy corpus is live: seven documents served under /ags/policies/.
