GIAL

General Integration Abstraction Layer

One uniform abstraction for connecting to the services the world runs on — Gmail, Google Drive, GitHub, or any HTTP API — in the tradition of Zapier and n8n: integrations, connections, actions, and logged executions. The connection layer the rest of the toolbox orchestrates over; deliberately not a workflow engine.

designed — not yet implemented The full design is written — concepts, taxonomy, authentication, adapters, API surface, storage, and the playground. This plate reserves GIAL's place in the toolbox; the spec lives at spec/gial/.
The Model
INTEGRATION
A connector definition — one Python adapter per external system, declaring its auth scheme and action set. The unit of capability.
ACTION
One operation with a declared parameter schema — write, search, find-or-create; triggers reserved. The unit of work.
CONNECTION
A configured instance — settings plus credentials held server-side, masked at every API edge. The unit of access.
EXECUTION
A logged run — request, response, status, latency. The unit of evidence.
