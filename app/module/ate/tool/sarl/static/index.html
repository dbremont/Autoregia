SARL

Sistema Asistencia de Revisión Lingüística

The copy editor's pass over the agent's texts: it verifies and corrects the linguistic, stylistic, terminological, and orthotypographic aspects of a submitted text — returning evidence-cited findings with suggestions, from which a corrected text is composed by explicit disposition. Deliberately not a writer and not a translator: it composes nothing; it verifies and corrects what already exists.

designed — not yet implemented The full design is written — model, dimensions, engine stance, rule packs, API surface, storage, and the plate. This plate reserves SARL's place in the toolbox; the spec lives at spec/sarl/.
The Model
TEXT
The submitted work — content, language (Spanish first-class, English), register, glossaries to enforce. The unit of work, never mutated in place.
RULE
One defect class — dimension, severity, deterministic matcher, message, suggestion strategy. The unit of criteria.
FINDING
One detected issue — exact span, quoted evidence, suggestion(s), and a disposition: pending, accepted, rejected. The unit of evidence.
GLOSSARY
A terminological authority — preferred terms, forbidden variants, aliases, per language and domain. The unit of terminology.
REVIEW
One logged pass — findings, dispositions, counts, and the corrected text with its change log. The unit of a review session.

The Pass
01
Review
The text is submitted with its language, register, and dimensions; the live packs raise findings, each citing its exact span.
02
Disposition
Every suggestion is accepted or rejected by the agent; rejections are recorded — repeated ones retire or retune the rule.
03
Apply
Accepted suggestions compose the corrected text beside a change log — span, rule, before → after. Nothing is ever overwritten.
